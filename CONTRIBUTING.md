# Contributing to NEUROX

Thank you for your interest in NEUROX, an experimental AI software project.

## Current stage

The repository currently contains early-stage documentation. A verified source-code release, reproducible demo, and public benchmark suite have **not** been published yet.

Contributions are welcome in the form of documentation corrections, reproducibility suggestions, design feedback, and well-scoped technical proposals.

## Before proposing a change

1. Review [README.md](README.md), [ARCHITECTURE.md](ARCHITECTURE.md), and [ROADMAP.md](ROADMAP.md).
2. Open an issue explaining the problem or proposed improvement.
3. Separate observed behavior from assumptions and planned features.
4. Avoid posting API keys, wallet secrets, personal information, or third-party code without appropriate permission.

## Pull requests

- Keep changes focused and explain the motivation.
- Include reproduction steps for bugs or testing instructions for technical changes.
- Update relevant documentation when behavior or design changes.
- Do not claim benchmark results without methodology and reproducible evidence.
- Do not introduce dependencies or external services without documenting their purpose and security implications.

## Project boundaries

This repository is for AI engineering, experimentation, and documentation. Keep financial promotions, token marketing, and speculative claims out of issues and pull requests.

## Review

Submissions may be revised, declined, or deferred. Opening a pull request does not guarantee acceptance.
